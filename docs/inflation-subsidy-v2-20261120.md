# 两套补贴算法 v2 本地实施

用户授权subagent规划后修改，先完成本地，未发布云端。此前商品库及保存提速改动保留。

## 已实现口径

新增shared/tradeInSubsidy.mjs统一计算：P可达门槛内选E最大，同额取最高可达门槛并带上同条规则A；H=P+E命中常规门槛，返回该行总额剔除本行膨胀后的J/B；C=P+A比较物品竞争力（相等算赢），D=P+E+J为到手价，K=P+A+B为全ahs承担报价。K沿用4.66%、基准价2.18%及81元费用项计算边际。膨胀不套娃。

候选搜索遍历合法取整价格，保留取整原始输入避免250→245→240二次取整。常规先选达到TM103%并满足利润底线的最低裸价，否则选利润底线内最高裸价，无解保留；追前亏损和已具备竞争力的保护保留。100%竞争模式不以利润拦截。自动30元到手补追、手动改价、两步到手追价、小差额容忍均接入同一计算。

手工和飞书支持11列，F:I四项只存档。原ahsInput/jdSubsidy在规则中继续保存原始总额，运行时按各命中行拆净额，避免重复扣除。用户确认J/K空白按0（含J已填而K空白的情形）。新格式严格识别带“含京东券”的总补贴字段，不会误取仅存档的同名分项；负数、拆后负数和活动金额冲突阻止正常导入。

新增规则ruleVersion=2、产品/快照pricingAlgorithmVersion=inflation-v2；旧格式和自营走原计算分支，旧快照原值不重算。新快照冻结两套规则和全部膨胀字段。

工作台新增追前/后E/A/C/H八列；v2把已有承担列明确命名为“以旧换新补贴ahs承担”（净B），全承担报价为K。Excel使用MAXIFS最大膨胀、同额最高门槛配对A，再用H查净J/B，公式与缓存值同口径。风险矩阵显示净补贴，跨系列利润比较使用完整A+B；等级推算保留3%与等级顺序策略，并冻结全部v2请求/展示字段。
