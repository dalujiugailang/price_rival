# 补贴承担矩阵 · 工作台同步版

入口：京东换新 → 追价工作台 → 等级推算右侧「风险测算」。页面延续系统的黑色细边框、方形控件、灰色表头与黑底选中态，保留热力单元格的业务色阶。

## 数据只用本次工作台

当前草稿使用 `activeCalculatedItems` 和 `activeState.subsidyRules`。展示共享快照时成套使用 `readOnlySnapshot.products` 与 `restorePayload.subsidyRules`，来源文件也读取同一快照。快照没有保存规则时提示缺失，不回退其他版本，更不会使用独立种子表。

模块没有单独上传、版本选择或数据接口。工作台原有「数据源」更新补贴表后，矩阵自动跟随当前测算变化；已有快照维持其冻结规则。此前独立接口、种子表和接口测试已移到各自同目录 `.archive`，历史独立版本数据保留但不再读取。

## 在用系列

默认展示全部系列；筛选框内的「只看目标新机系列」按钮可切换到当前工作台在用系列，与品牌、系列、关键词联动，Excel 导出跟随当前范围。本次工作台 `newSeries` 精确匹配的系列保留「目标」标记和对应报价条数，并排在前面。使用统计不借用旧机品牌。新机品牌只来自补贴规则原始字段，没有就显示「未提供品牌」。同系列跨多个品牌标签在矩阵统一成一行，实际命中仍按系列计算。

在用但没有有效规则的系列保留空行并提示。原始规则按序号保留，补贴明细不丢失；没有真实原表行号时标为工作台规则序号，不假设 Excel 行号。

合并门槛仅控制展示：每组最高与最低不超过 10 元，不做链式延伸。每格按最大承担着色，不同承担显示区间，多规则显示 ◈，点击展示该新机系列的全部规则，并框选刚点击的合并档所有原始规则，自动滚入视口。矩阵只展示承担金额，已移除「同档增亏风险」切换；保留同档差额 Δ 供参考。品牌、新机系列精确筛选、门槛、搜索和显示统计在同一个可换行工具栏中，失效筛选随来源更新自动回退。

## 新机 / 旧机两个视角

新机视角固定一个目标新机系列，直接检查全部工作台 PPV 报价，逐条使用各自的「京东物品价-追价后」计算换到所选新机后的承担和预计利润；不再区分对应机型和全部测算两个范围。亏损最多的报价优先显示。每个 PPV、等级和来源方案分别保留，已对应关系与跨系列测算明确标注，不据此预测真实换新订单量。

旧机视角选择一条工作台报价，直接读取「京东物品价-追价后」，列出换到各目标新机的补贴差异、预计利润和亏损/低利润风险。两个视角复用同一场景计算，反向查看同一组合的数值完全一致。

利润区只保留必要选择，报价、补贴和利润均取工作台已算结果。列表按预计亏损额降序，可只看亏损/低利润，点击「查看原因」追溯实际原始门槛。

单一复用现有系统口径：

- 基准利润额 = 该行已算 `postMarginalProfit × basePrice`；基准补贴 = `ahsSubsidyAfter`，不通过矩阵重算覆盖。
- 实际补贴按 `newSeries` 和追后旧机物品价达到的最高**原始**门槛命中，互斥、不叠加。品牌标签不参与适用条件。
- 目标系列补贴增量 = 目标实际承担 − 当前工作台承担。
- 预计利润额 = 当前利润额 − 补贴增量 × 1.0466；预计利润率 = 预计利润额 ÷ 该旧机 `basePrice`。
- 4.66% 来自现有换新公式中的线性费用；每多承担 100 元补贴，利润减少 104.66 元。用户无需选择计算模式。
- 利润率为负时标亏损；非负但低于工作台 `marginBottomLine` 标低利润，其余正常。零线/底线比较使用微小浮点容差，避免正好达标误报。
- 同一最高原始门槛有不同金额、无有效规则、无效金额、旧机基准价不大于零等情况显示待核验，不猜测 0 补贴，也不将合并档最大值强行用于订单。
- 当前方案保持工作台已算结果；其他系列的比较仅作风险提示，不修改正式追价、补贴表或历史快照。

## 导出

导出仅包含一张「补贴承担热力图」工作表：使用当前筛选行、门槛列和排序，复用网页六档色阶，保留金额范围、多规则标记、目标系列、两行表头、行列尺寸、图例和业务提示。Excel 冻结表头与首列。原始规则和利润分析仍在网页查看，不再附加到导出。使用已安装的 @office-kit/xlsx 写入原生单元格样式。

### 承担比例视图（2026-11-04）

筛选框内可切换「承担金额 / 承担比例」。承担比例逐条按爱回收承担额 ÷ 原始门槛计算，显示两位百分比；多规则保留各自门槛与承担额配对形成的比例范围，颜色和表头排序取最大比例。门槛为0的规则显示待核验，避免除零。色阶为 <10%、10–<20%、20–<30%、30–<50%、50–<70%、≥70%；表头Δ使用百分点（pp）。Excel沿用当前模式、颜色、百分比格式及排序。利润比较仍使用原有实际补贴命中与利润计算。

表头「最大差额 Δ」按当前筛选后可见系列计算：金额为最高承担减最低承担，比例为最高比例减最低比例（pp）。目标系列、品牌、精确系列及关键词筛选均生效；无有效值显示—，单个有效值为0。风险差额TOP10也按筛选范围和当前显示模式重新排名；Excel表头复用同一计算。

### 补贴口径切换（2026-11-04）

Subagent规划与实施复核后，新增独立「爱回收承担 / 总补贴（含京东券）」切换，和金额/比例正交。默认爱回收承担金额；保持筛选条件、目标开关和排序方向。

- 爱回收承担读取 `ahsInput → ahs`；总补贴直接读取 `jdSubsidy → jd`，原表字段「京东总补贴（含京东券）」。不计算 `jd + ahs`，不从其他字段推算总补贴。
- 比例逐条用当前补贴金额除以原始门槛，允许超过100%；显式0金额有效，门槛0时比例待核验，缺失/异常金额待核验，无规则为—。
- 多规则完整保留，矩阵展示当前字段的范围，颜色和排序用最大值；单元格仍可展开两种原始金额及当前口径比例。
- 表头Δ、筛选内最大差额与TOP10按当前筛选系列、补贴口径、金额/比例实时重算，比例Δ使用百分点pp。金额和比例各沿用固定六档色阶，保证两个补贴口径可比较。
- Excel仍只输出单张热力图，标题、文件名、字段、比例、颜色、Δ和行顺序跟随页面。
- 利润测算仍使用命中规则的爱回收承担金额，所选总补贴不作为爱回收成本，也不改变基准利润和利润率分母。页面「补贴口径与展示规则」明确展示以上口径。
