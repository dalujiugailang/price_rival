# 价格分析性能改造与验收（2026-10-23）

## 原因与范围

原接口每次读取、解析并返回完整快照，包括原始上传字段和用于恢复的重复商品数据，还叠加了分析不使用的等级投资计算。进入分析和窗口重新聚焦时可能同时请求全局完整历史。

本次改为独立的分析字段投影、SQLite 版本触发器与持久化派生缓存、压缩结果复用、ETag 条件请求、前端请求合并和按账号/权限版本隔离。分析激活时不再额外刷新全局历史。新增“刷新分析数据”入口。

追价算法、建议规则、缺失值处理、历史存档与价格分析独立权限不变。新增缓存表和触发器；新增、修改、软删除、硬删除快照都会失效缓存。缓存及 304 判断之前仍验证权限。

## 本地验收

在正式数据的 SQLite 副本上测试，只统计未删除的 55 份快照、9,626 条商品；不把软删除存档计入接口数据量。

| 指标 | 原实现 | 优化后 |
|---|---:|---:|
| JSON 字节 | 29,126,546 | 7,155,821 |
| gzip 字节 | 3,214,924 | 840,489 |
| 单次冷生成 | 499 ms | 365 ms |
| 热缓存未变化请求 | — | 中位 0.0024 ms、正文 0 字节 |
| 服务重启后的持久缓存校验 | — | 9.7 ms |

gzip 减少约 74%。220 项逐批建议、时间标签、PPV 索引、相邻批次聚合及品牌/系列层级一致性核对通过。构建、TypeScript 检查、服务端独立权限与缓存失效测试、前端请求合并/账号隔离/退出清理/权限撤销测试、分析渲染回归和 API 响应解析测试通过。

云端同样是 55 份快照、9,626 条商品，gzip 减少约 74%。SQLite quick_check=ok；无权限在缓存 304 前被拒绝；HTTP 未登录访问分析返回 401；认证配置接口返回 200；应用启动正常，开发登录关闭。
