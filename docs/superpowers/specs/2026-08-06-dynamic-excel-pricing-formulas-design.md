# 动态 Excel 追价试算导出设计

## 目标

将现有“导出追价表”升级为可在 Excel 中继续试算的工作簿。用户修改“试算追后价”后，补贴门槛匹配、追后价格指标、利润率和竞争判断立即随 Excel 公式更新，同时保留系统生成的正式推荐结果用于对照。

## 范围

- 保留现有按页面筛选结果导出的行为、两行表头、源字段和文件命名。
- 支持京东换新和自营两个渠道各自的补贴与线性费用口径。
- 使用用户指定的 `XLOOKUP` 公式进行动态补贴门槛匹配。
- 不在 Excel 中重新实现系统的推荐价生成、价格取整或边际底线反推算法。
- 不改变页面内的追价计算、历史快照或正式竞争力落数逻辑。

## 工作簿结构

### 追价表

在现有导出列基础上明确区分系统结论和 Excel 试算输入：

- 新增“系统推荐追后价”，写入导出时的 `recommendJdPrice` 静态值。
- “京东物品价-追价后”调整为“试算追后价”，初始值等于系统推荐追后价，允许用户直接修改。
- “京东物品价-追价后理由”和“小差额提醒”分别改为“系统追价理由”和“系统小差额提醒”，保持静态，避免用户改价后误认为系统结论已变化。
- 价格、补贴、费用和利润率使用数值单元格与 Excel 数字格式，不再输出带人民币符号或百分号的文本。

### 补贴规则

新增可见工作表“补贴规则”：

- 京东换新导出新机系列、价格门槛、AHS 投入、京东补贴及全部可追溯源字段。
- 自营导出价格门槛、AHS 投入及全部可追溯源字段。
- 规则按新机系列和价格门槛升序排列；自营按价格门槛升序排列。
- 追价表公式只引用必要的标准列，额外源字段仅用于核对。

### 测算设置

保留现有“测算设置”工作表，并继续记录渠道和当前追价模式/利润底线。工作簿设置为打开时自动完整重算。

## 动态公式

数据从两行表头后的第一行开始。公式按列名解析出的实际 Excel 列字母生成，不依赖固定列位置。

### 补贴门槛匹配

京东换新使用多条件 `XLOOKUP`：同一新机系列内，寻找小于等于试算追后价的最后一个门槛。

```excel
=IFERROR(XLOOKUP(1,(补贴规则!新机系列=本行新机系列)*(补贴规则!价格门槛<=本行试算追后价),补贴规则!AHS投入,0,0,-1),0)
```

京东补贴使用相同条件返回京东补贴列。自营不带新机系列条件，只按价格门槛匹配。某系列有规则但试算价格低于首个门槛时返回 0；京东换新某系列完全没有规则时，分别沿用该行当前 AHS 投入和当前京东补贴，与系统的无规则回退口径一致。自营没有规则时返回 0。

### 追后联动列

以下列以“试算追后价”为输入，通过公式动态刷新：

- 追后 AHS 补贴：从“补贴规则”匹配。
- 追后京东总补贴：京东换新从“补贴规则”匹配；自营为 0。
- 追后含 AHS 补贴报价：试算追后价 + 追后 AHS 补贴。
- 追后京东总到手价：试算追后价 + 追后京东总补贴。
- 追后调整金额：试算追后价 - 当前 JD 裸机价。
- 追后边际利润率：按渠道线性费用公式重算。
- 四项追后竞争判断：继续使用严格 `>`，分别对比 TM 物品价、TM 到手价、ZZ 物品价和 ZZ 券后价。

京东换新追后线性费用为：

```text
(试算追后价 + 追后 AHS 补贴) × 4.66% + 基准价 × 2.18% + 81
```

自营追后线性费用为：

```text
基准价 × 2.18% + 63
```

边际利润率在基准价小于等于 0 时返回 0，避免除零错误。

## 保留的系统结果

以下内容保持导出时的静态值，不随 Excel 手动试价重新生成：

- 系统推荐追后价。
- 系统追价理由。
- 系统边际底线最高价及其说明。
- 系统小差额提醒。
- 推荐价取整、100% 竞争力推荐和按补贴区间反推最高价的内部过程。

这些字段描述系统当次正式测算；动态列描述用户在 Excel 中的试算结果，两者不混用。

## 异常与兼容性

- 如果未加载补贴规则，仍导出“补贴规则”表头；京东换新动态补贴公式沿用该行当前补贴，自营动态补贴公式返回 0。
- `XLOOKUP` 以 Microsoft 365 / Excel 2021 及支持该函数的 WPS 为目标环境；旧版 Excel 不在本次兼容范围内。
- 工作簿写入自动重算属性，确保首次打开时刷新公式。
- Excel 公式分隔符按 `.xlsx` 标准使用英文逗号，由本地 Excel 负责显示适配。

## 验证标准

1. 导出后，“补贴规则”可见且内容与当前渠道已加载规则一致。
2. “试算追后价”初始值与系统推荐追后价一致，初次打开时所有动态结果与页面计算结果一致。
3. 将试算追后价跨过一个补贴门槛后，AHS 补贴和京东补贴匹配到新档位。
4. 同次改价后，调整金额、追后报价、追后到手价、边际利润率及四项严格 `>` 判断同步变化。
5. 京东换新和自营分别使用正确的补贴匹配条件和线性费用公式。
6. 原始字段、系统推荐结果和系统说明仍可追溯。
7. `npm run lint` 与 `npm run build` 通过。

## 测试策略

- 将工作簿构建逻辑提取为纯函数，并用固定样例的程序化检查验证工作表、列类型、公式引用和重算设置，不额外引入测试框架。
- 覆盖京东换新多系列门槛、自营通用门槛、无规则、基准价为 0 和严格大于边界相等的场景。
- 生成一个样例工作簿并解析回读，确认公式单元格包含预期 `XLOOKUP`、数值格式和工作表结构。
