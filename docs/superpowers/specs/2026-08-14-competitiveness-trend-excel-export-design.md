# 竞争力走势 Excel 导出设计

## 目标

在“历史追平周期竞争力波动走势”主图提供【导出Excel】按钮，导出一个包含总盘和各品牌趋势的 `.xlsx` 文件。每个 Sheet 同时包含 Excel 原生可编辑折线图和对应数据表。

## 导出范围

- 导出范围跟随页面当前的【近15次追价 / 全部】选择。
- 品牌下拉框只控制页面展示，不限制导出内容；每次导出始终包含总盘和全部有数据的品牌。
- 总盘使用现有总趋势时间线，保留纯汇总历史节点。
- 品牌使用现有品牌时间线；某期没有该品牌 PPV 明细时不生成该节点。
- 今日工作台节点继续标记为实时草稿。

## 工作簿结构

- 第一个 Sheet 固定命名为【总盘走势】。
- 后续按页面品牌排序，每个品牌生成一个独立 Sheet；Sheet 名清理 Excel 禁止字符并限制为 31 个字符，发生重名时追加序号。
- 每张 Sheet 顶部放置一张 Excel 原生折线图，图下放数据表。
- 数据列固定为：日期、批次、节点类型、天猫到手价竞争力、天猫物品价竞争力、物品价+AHS补贴 vs 转转到手价、转转物品价竞争力。
- 竞争力数值写成 Excel 百分比数值，保留一位小数显示，不写成文本。
- 文件名为 `竞争力走势_总盘及品牌_YYYY-MM-DD.xlsx`。

## 图表

- 图表类型为 Excel 原生折线图，可在 Excel 中点选系列并继续编辑。
- 横轴为日期节点，纵轴固定为 0%–100%。
- 四个系列与页面保持同名和同色：天猫到手价、天猫物品价、AHS 补贴后对转转到手价、转转物品价。
- 图例放在底部，图表标题使用【总盘竞争力波动走势】或【品牌名 竞争力波动走势】。
- 图表引用同 Sheet 下方的数据区域，用户修改数据时图表随 Excel 重算刷新。

## 实现边界

- 前端复用现有总盘、品牌时间线和范围筛选，整理为不含 PPV 明细的导出数据。
- 前端通过受登录保护的导出接口提交工作簿数据；服务端使用 Node 侧 Excel 图表生成库返回文件流，保持现有 Alpine/Node 部署结构，不引入 Python 运行时。
- 导出按钮沿用当前硬边框工业风，放在品牌筛选框旁边。
- 导出失败时在按钮附近显示简短错误，不影响页面图表和工作台数据。

## 验证

- 纯函数测试覆盖总盘与品牌 Sheet 数据、近15次/全部范围、百分比转换、Sheet 名清理与去重。
- 接口测试确认未登录拒绝、空数据报错、响应文件名和 MIME 类型正确。
- 工作簿结构测试确认总盘 Sheet 位于首位、各品牌 Sheet 齐全、每张 Sheet 含四系列原生折线图和数据表。
- 运行 TypeScript 检查与生产构建。
- 在 5001 页面分别导出近15次和全部范围，实际打开 Excel 验收 Sheet、图表和数据引用。
