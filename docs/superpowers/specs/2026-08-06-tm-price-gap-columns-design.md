# TM 追前追后价差列设计

## 目标

在京东换新竞争追价表中增加四个天猫价差列，分别展示追价前后 JD 物品价与到手价相对 TM 的绝对价差。页面和导出 Excel 使用同一业务口径，导出后修改相关价格时价差公式能够自动重算。

## 列位置与公式

在 `追前边际利润率` 右侧依次插入：

- `追前tm物品价差 = jd裸机价 - tm裸机价`
- `追前tm到手价差 = jd总到手价 - tm总到手价`

在 `追后边际利润率` 右侧依次插入：

- `追后tm物品价差 = 京东物品价-追价后 - tm裸机价`
- `追后tm到手价差 = jd总到手价-追价后 - tm总到手价`

四列均为金额，页面使用现有人民币格式展示。

## 有效值与配色

- 对应 TM 比较价格大于 0 时才计算价差。
- TM 比较价格缺失、无法解析或小于等于 0 时，页面显示 `-`，导出单元格返回空字符串。
- 价差大于 0 使用绿色字体。
- 价差小于 0 使用红色字体。
- 价差等于 0 使用默认黑色字体。

物品价差只依赖 `tm裸机价` 是否有效；到手价差只依赖 `tm总到手价` 是否有效。两者互不连带，避免一个 TM 字段缺失时隐藏另一个仍可计算的结果。

## 页面实现

新增一个纯函数模块，集中返回四个可选价差，避免 `MainTable` 在展示和导出值生成处重复公式。`MainTable` 负责：

- 在固定列定义中插入四列的编码、标签、宽度和展示单元格。
- 根据纯函数结果展示金额或 `-`。
- 根据数值正负选择红色、绿色或默认字体。
- 调整后续固定列索引，包括追价理由筛选、小差额容忍表头、隐藏说明列和自营渠道隐藏列。

四列只适用于京东换新。自营渠道页面与导出均隐藏，保持现有自营口径不引入 TM 字段。

## Excel 动态公式

导出追价表时四列随固定列一起出现。动态工作簿增强逻辑根据第二行中文列名定位字段，不依赖固定 Excel 字母：

- `追前tm物品价差`：`IF(tm裸机价>0,jd裸机价-tm裸机价,"")`
- `追前tm到手价差`：`IF(tm总到手价>0,jd总到手价-tm总到手价,"")`
- `追后tm物品价差`：`IF(tm裸机价>0,京东物品价-追价后-tm裸机价,"")`
- `追后tm到手价差`：`IF(tm总到手价>0,jd总到手价-追价后-tm总到手价,"")`

公式缓存值使用页面相同的纯函数结果。金额格式沿用 `#,##0.00`。页面配色为必需行为；Excel 保证动态公式与数值口径，字体配色仅在当前 SheetJS 写出能力能够稳定保留时添加，不引入新的工作簿依赖。

## 测试与验收

1. 纯函数覆盖正数、负数、零值和 TM 无效四类边界。
2. 页面四列分别位于两个边际利润率列右侧，正绿、负红、零黑、无效显示 `-`。
3. 新增列后追价理由筛选、小差额容忍按钮和后续单元格仍与表头对齐。
4. 自营渠道页面与导出均不出现四个 TM 价差列。
5. Excel 四列包含动态公式；修改 JD、TM 或追后价格后可重新计算。
6. 现有追价逻辑、小差额容忍、竞争力和导出公式测试保持通过。
7. 运行针对性测试、`npm run lint` 和 `npm run build`，并在端口 5001 验收页面列位置与配色。
