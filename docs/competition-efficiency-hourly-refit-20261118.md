## 模型与验证

各期等权。均值、非负斜率线性、Logistic、Gompertz、GCV平滑样条、局部二次平滑共6种方法。局部带宽在每个训练折内部重选；S型模型的参数边界依据该训练折X设定，固定k在[0.005,3]、幅度在[0,200]。GCV平滑也在训练折内重新拟合。

主排名为留一期RMSE（每期分别留出预测，训练不使用该期Y）。时间预测是前8期起，每次用已发生的期预测下一期，共9个预测，作为另一项核验；它不是另取的独立数据集。不同模型在同一批17期比较，排名不等于概率置信度，也不等于因果验证。

| 模型 | 留一期RMSE(pp) | 时间预测RMSE(pp) |
| --- | ---: | ---: |
| 均值基线 | 4.4973 | 0.9649 |
| Logistic | 5.0571 | 1.1586 |
| 单调线性 | 5.0680 | 0.9649 |
| Gompertz | 5.1086 | 1.1695 |
| GCV样条 | 5.8161 | 0.7052 |
| 局部平滑（内层选带宽） | 5.8827 | 2.0534 |

整体留一期排名均值基线最佳；Logistic为曲线中相对最佳，但误差比基线高约12.45%，k=3触及上限。其最陡位置82.24%只是数学探索值，删一期后约76.99%至90.11%，不作为日常目标。GCV在最近9个时间预测中误差更低，但整体留一期更差；两种检查未一致支持同一条响应曲线。

结论：旧79%候选停用。当前17个覆盖期没有识别出可信的日常边际效用最高点，不据此提高或降低全量策略，也不解释为竞争力没有作用。常数基线的预测均值为2.8926pp，只是本窗口Y的预测基准，不是可保证的业务增量。
