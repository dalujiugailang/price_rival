# 等级推算与投入测算

## 定价规则

自动跟随重点追价的全部 SKU。只有实际加价的 SKU 扩展；从正调整记录中选最低追后京东物品价为首次基准。调整额取原重点追价记录，不由最新 Daily Price 反推。

按 SKU 所属型号匹配模板，从最高已定价等级起向下覆盖六档，含起始等级；已有价格保留，包括六档外已有价格。新增价格为基准价乘目标等级比、除以基准等级比，再按现有规则取整。重复 PPV 的不同已定价需显式选择。

新增等级固定守住 3% 边际利润率底线，不随重点追价底线改变。用目标 PPV 的 BI 基准价及新机系列补贴规则，寻找不高于比例价且满足底线的最高可用报价；重新匹配补贴和取整。缺必要价格资料时不输出未校验价格。

出现低等级价格更高时，选倒挂位置上方最低的未倒挂等级作为参考，按比例重算后续新增等级，重新验证利润和价格顺序，循环修正。已有价格不自动改变，无法解决的冲突保留状态提示。

## 活动量与费用

完整 PPV 底表按 SKU 和等级提供近30天报价量及成交量，缺失活动量默认 0。原文件与全量底表按内容哈希、周期保存，重复导入不累计量。

新增投入 = max(最终推算价 − Daily Price 最终报价, 0) × 近30天成交量。零成交投入为零；低于策略价仍展示负调整额，投入不为负。有成交但缺必要价格时保持待补。旧测算读取时兼容缺失量默认零，不改写原件或重新计算冻结价格。

## 保存与费率

实时测算不自动确认投入。先保存重点追价快照，再保存等级推算到本期历史；保存即确认额外投入。每期仅一个最终版，新版替换旧版，不累加费用，操作日志保留。

费率仅加入已确认最终版中的新增等级费用，重点追价费用不重复加入。整体和品牌各自使用对应销售额分母；保存时冻结可用分母。未保存的测算不计入费率，旧确认投入不混入价格已改变的新测算。新增等级始终不进入竞争力汇总。

## 页面与发布

业务人员在重点追价调价，进入等级推算核对底表、周期、模板、状态和投入，再确认保存。明细与 Excel 沿用重点追价列序，竞品缺失字段显示“-”。没有本地草稿时，编辑人员切换底线会将共享快照的原始价格复制为实时测算输入，历史原快照保持不变。

验证包含等级、追价、费用、权限、历史与草稿测试，以及类型检查和构建。发布仅包含源码、测试及文档，不包括本地上传原件、数据库、测算结果、密钥及构建产物。云端继续使用自身数据卷，新的底表、模板和测算由业务操作产生。
