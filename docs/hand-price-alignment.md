# 筛选 PPV 的到手价两步追价

仅在京东换新可编辑工作台展示。“到手追价”按钮放在常规边际底线输入框旁，点击展开操作面板，再次点击、点击外部或按 Escape 收起；不占表格宽度。使用当前列筛选与搜索共同命中的全部行，按源行身份隔离同 PPV 的不同新机系列。

1. **到手追至 TM 103%**：在常规追价及既有手动价格的基础上，寻找使 `追后京东到手价 >= TM到手价 × 1.03` 的最低合法物品价。已达标不降价；允许原边际为负；本步不受回调底线约束。
2. **边际底线回调**：单独点击执行；底线默认 -5%，输入支持 -100% 至 100%。仅对第一步成功处理、当前仍被筛选命中、且边际低于底线的行降价，寻找不超过当前价格、满足边际底线的最高正数合法物品价。可低于原始 JD 物品价，也可失去 TM 103% 或 TM 到手价竞争力。不存在可行价格时保留原价并明确提示仍未达底线。

计算逐补贴区间反推候选，最终按现有物品价取整规则重匹配 AHS、京东补贴并复核边际。由于补贴跳档和价格离散，回调后的边际可能高于设定底线。250→245 等非幂等取整保留原始输入，避免草稿重算时二次取整。

没有补贴表时沿用完整的基础补贴字段；已上传补贴表却无法匹配新机系列时跳过。缺少有效 TM 到手价、基准价、京东追后价格或补贴数据时不改价。

两步直接更新表格；不弹出对比或确认窗口。原因写入“小差额提醒”，可在单元格内展开查看完整两步说明；导出及历史快照保留完整说明。左侧可撤销最近一次操作。改价记录持久化在本地草稿，历史快照仍保留保存时的价格和原因。

调整保存为独立的逐行覆盖值，位于常规计算之后；基础价格、竞品价格、基准价、补贴或原手动价格变化使旧覆盖值失效，避免覆盖刷新后的计算。新增基础表上传清空旧覆盖值。自营和只读快照不提供操作按钮。

验证：`npm run test:hand-price`、`npm run lint`、`npm run build`。数值测试包含穷举合法价格对照、补贴跨档、非单调补贴、精确底线、245/250取整、205行筛选及重复PPV隔离、草稿恢复和基础输入变更失效。
