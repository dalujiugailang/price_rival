# 稳健与正则化替代模型探索

只读17期当前小时口径样本，不改主latest.json、UI或快照。独立脚本ops/explore_robust_efficiency.py，输出data/competition-efficiency/alternative-models/robust-models.json。

所有外层留期误差都在原始Y上计算，未删除任何高Y期。岭回归的惩罚参数在每个外层训练集内部再做LOO选择，X标准化也只用训练数据。Huber固定阈值2pp，Student-t自由度4、尺度为训练Y的MAD×1.4826且至少1pp；均为明确的敏感性设定，不用外层Y调参。

LOO每期一次，共17次；时间预测从前8期起预测下一期，共9次，与原比较一致。单位均为pp。

Student-t在典型期的绝对误差上有改善：MAE略低于中位数基线，中位绝对误差明显低于两种基线，但RMSE仍不及两种常数模型，时间误差也不及均值。不存在在所有验证口径上全面胜出的模型。

Student-t最大斜率位置68.84%，删除一期后约66.49%—69.95%；Huber为69.64%，删除一期66.59%—90.11%。两者陡峭度k都触及默认上限3，提示曲线实际接近一个跳变，斜率大小没有可靠识别。kmax=.3/1/3/10时，Student-t最陡位置67.30/67.87/68.84/70.35；Huber68.66/68.35/69.64/70.41。岭回归多数选中最强惩罚lambda1000，曲线趋于平坦；岭三次“最大斜率”仍为负数，不支持把其内部数学极值作为正效用最优点。

稳健拟合降低了两期高Y的影响，但高Y本身并非已确认错误。稳健模型更接近“典型期中心”而不是直接优化跨期平均Y；约69%与原82%差异说明损失函数与业务目标会改变取点。不能将降权解释为因果去混杂，不能把约69%包装成已证实的平均收益最优。
